## Project Overview
### Features:
  • Add, edit, delete tasks from list.
    o Allows users to create and manage tasks on the app.
    o Users can interact with buttons, text fields, and date pickers.
  • Build a daily itinerary to complete tasks
    o Feature creates a greedy-fill-by-urgency itinerary, filling up to eight hours.
      Allows users to complete the most important tasks first.
    o Users can go to the Daily Itinerary tab, and press "Rebuild" to create an
      itinerary.
    o Made these two separate views so the user can focus on each at different
      times.
  • Rank tasks by urgency with priority ranking
    o Allows users to categorize tasks into different levels of urgency
    o The user can select the priority ranking from a dropdown menu in the task
      creation view.
    o Used color coded styling to match the urgency of each priority level. High =
      red, medium = yellow, low = green.
  • Create custom categories for tasks
    o Allows the user to create a custom category; each user can organize their
      tasks according to their needs.
    o Category is added via text field in the task creation view.
  • Sort and filter tasks by priority, due date, and category.
    o Allows users to sort tasks by priority, due date, and estimated time to
      complete, as well as filter by priority, whether the task is overdue or
      upcoming, and custom categories.
    o Sort is controlled by a dropdown menu, and the filters are found in an
      interactive bar at the top of the task list. Each filter can be clicked on.
  • See a summary of all tasks separated into urgency and due date.
    o Helps the user keep track of task totals, such as total tasks, total overdue,
      etc.
    o The user can view the summary on the left side of the task list.
    o Color coding the summary line items helps draw user attention.
